# 当前问题、机器人回复与随机插嘴

本轮改进修复了单条提问只存在于历史、机器人发言依赖平台回显、已处理指令污染模型上下文，以及插嘴过度关注最后发言者的问题。

被 @ 或私聊时，Block F 明确包含当前提问正文、后端确认的发言者权限和本批待回应消息。当前正文中的链接、引用优先于历史中的旧话题；视频元信息不能作为观看画面、剪辑或声音的依据。

发送成功后，纯回复正文直接写入 LLM 使用的内存历史，明确标记为「你此前发送的回复」。调试推理、统计尾注不回流到模型；失败发送不记录为已说过的话。发送前登记原始发送内容，用于屏蔽近期匹配的机器人回显，避免重复历史或调试内容回流。WebUI 仍保留完整发送内容供回看。

指令解析移至聊天历史记录之前。已识别的指令，包括权限拒绝、过期指令，不进入模型历史；指令响应也标记为不进入上下文。未知文本仍作为普通聊天处理，指令权限规则不变。

随机插嘴时，Block F 单独呈现近期群聊讨论，保留所有人的发言、明确引用及机器人自己的回复。范围为触发时间之前的最近五分钟，最多二十条；连续发言间隔超过两分钟时停止向前回溯。每条最多六百字符，片段正文最多约四千八百字符，超出时按整条移除最旧发言。旧历史仍可作为背景参考，这个窗口不保证自动识别话题边界。

插嘴不再自动召回最后发言者的个人画像，提示模型先理解讨论主题、接话对象和自身此前发言，再决定是否补充一句。最后发言是触发机会，不代表群友向机器人提问。指代不清、内容重复或没有必要时可输出 `(empty)` 保持安静。

画像工具继续可用，主动维护稳定偏好的能力未禁用。画像辅助个性化表达，群聊讨论决定本次内容；发现真实、稳定的偏好时可以调用画像工具，不应因此转为人物点评。被 @ 时保留原有个人画像召回。

验证：Release 主程序编译通过，323 项测试通过；新增回归覆盖当前正文、指令隔离、成功回复入历史、发送失败与回显、多人讨论及引用、时间窗口和长度预算、插嘴与被 @ 的画像差异。测试验证结构与调用链，实际接话质量仍需群聊复测。
