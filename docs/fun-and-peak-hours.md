# 高峰不插嘴与反转句号

WebUI「配置 → 触发与节流」在随机插嘴概率下增加“高峰不插嘴”，配置键为 `Trigger.RandomChatSkipPeakHours`，默认关闭。开启后，按北京时间（UTC+8，与服务器时区无关）在 `[09:00,12:00)` 与 `[14:00,18:00)` 禁止普通群消息的概率插嘴。不改变正常 @ 回复、指令、暖群或纯规则 Fun 功能，也不阻止链接解析与资料直发。时段按本次触发判断时间计算。

WebUI「配置 → 随机互动」增加“反转句号”，配置键为 `Fun.EnableReversePeriod`，默认关闭。开启后，去除 @ 标签并修剪首尾空白；若正文以全角句号 `。` 结尾，去除末尾连续句号，取句号前最后至多五十个字符倒序排列，再补一个句号。按完整 Unicode 文本元素处理，不拆开 emoji 和组合字符。半角句号 `.` 不触发。

例如 `作品相关素材均来源于网络。。` → `络网于源来均材素关相品作。`。超过五十个字符只处理靠近末尾句号的五十个字符；纯句号消息返回一个 `。`。

反转句号优先于反驳、反向艾特、随机 OSM、复读和叫哥；命中后不再执行其他随机互动或该消息的 LLM 回复。适用范围与原 Fun 一致：群聊中的正常有效消息，私聊、命令、机器人自己的消息和已处理副作用的重复事件不触发。链接解析与资料直发已经在 Fun 前完成。

可通过 `/admin set Trigger.RandomChatSkipPeakHours true` 和 `/admin set Fun.EnableReversePeriod true` 热更新；`/fun` 会显示反转句号状态。
