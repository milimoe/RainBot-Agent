# 应用语言风格 Skill

不提供默认语言风格。用户在人设页打开「语言风格管理」模态窗，填写风格名称并上传 SKILL.md，服务端将原文保存到运行目录的 `skills/styles/style_{name}.md`。也可以手工将同样命名的 Markdown 文件放入该目录。名称支持 1–64 个字母、数字、中文、下划线或连字符，正文最多 30000 字符；上传同名文件不会覆盖原文件。

每个人设具有「应用语言风格 Skill」开关，默认关闭。上传只保存文件并选中风格，不自动打开开关。开启、选择风格并保存人设后，关联实例下一轮对话使用「固定群聊伙伴模板 + 风格文件」。使用者只需设置机器人名称，不必编写人设。开启风格模式时若未填写正文，保存会填入固定模板。

关闭开关并保存后，BOT 使用该人设保存的普通正文，不加载风格文件；原有正文和提示词设置保留。运行时组合风格，不将 Skill 复制进人设文件；文件内容的修改下一轮生效。启用模式下风格文件缺失或损坏时回退固定模板，不加载其他风格。

固定模板定义身份、性格和回复原则：先回答当前问题，再按风格表达；原 Skill 的按需改写条件在日常风格模式下不适用。加载时去掉 YAML 元数据，不执行脚本或加载相对路径依赖。代码、命令、链接、数字和关键事实保持准确，用户要求直说时优先可理解性。现有隐私、工具使用和群聊礼仪规则保留，语言风格不会改写直接发送的链接解析卡片。

API：`GET /api/webui/language-styles` 返回已上传的文件列表；`POST /api/webui/language-styles` 接收 `name` 与 `skillMarkdown`，保存文件并返回 `style` 和 `styles`。开关和选择保存在人设的提示词设置 `languageStyleEnabled`、`languageStyleName` 中，沿用现有保存 API 与鉴权。

模态窗集中提供上传、文件列表与删除。删除需要确认；仍被已保存人设启用的风格不能删除，需先关闭开关或更换风格并保存。删除 API 为 DELETE /api/webui/language-styles/{name}。
